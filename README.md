# theyuchen.github.io

Personal academic homepage of Yuchen (Ethan) Yuan.

Built with Jekyll. Hosted on GitHub Pages.

## Local Development

```bash
gem install bundler
bundle install
bundle exec jekyll serve
```

Then visit `http://localhost:4000`.

## Content Guide

| What to edit | Where |
|---|---|
| Site settings (name, URL) | `_config.yml` |
| Home page | `index.html` |
| About page | `pages/about.md` |
| Publications | `pages/publications.md` |
| CV | `pages/cv.md` |
| Research blog posts | `_research/YYYY-MM-DD-title.md` |
| General blog posts | `_thoughts/YYYY-MM-DD-title.md` |
| Projects / demos | `_projects/title.md` |
| Profile photo | `assets/images/profile.jpg` |
| CSS styling | `assets/css/style.css` |
