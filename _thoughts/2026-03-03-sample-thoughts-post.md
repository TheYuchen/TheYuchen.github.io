This is a sample post in the "Thoughts" section. This space is for your writing that goes beyond your core research, such as reflections on academia, life as a PhD student, technology and society, or anything else you want to share.

## How to write a new post

1. Create a new `.md` file in the `_thoughts/` folder
2. Name it: `YYYY-MM-DD-your-title.md`
3. Add the front matter at the top
4. Write freely in Markdown

Delete this sample post once you start writing your own content.
